2. О приложении

Feel Power предназначено для планирования тренировок, хранения истории занятий и работы с персональным аккаунтом пользователя.

3. Аккаунт пользователя

Для использования части функций приложения требуется регистрация. Пользователь отвечает за корректность указанных данных и сохранность данных для входа в аккаунт.

4. Допустимое использование

Пользователь обязуется не использовать приложение для нарушения законодательства, доступа к чужим данным, вмешательства в работу сервиса или злоупотребления его функциональностью.

5. Данные тренировок

Приложение может сохранять созданные пользователем программы, упражнения, тренировочные сессии и связанные настройки, необходимые для работы сервиса и отображения прогресса.

6. Удаление аккаунта

Пользователь может удалить аккаунт в разделе профиля приложения. После удаления аккаунт и связанные с ним данные удаляются, кроме сведений, которые оператор обязан хранить в силу закона.

7. Изменение условий

Оператор вправе обновлять настоящее соглашение. Актуальная версия всегда размещается на этой странице.
